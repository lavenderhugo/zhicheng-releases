# 职程（Zhicheng）

一个面向 macOS 的本地优先求职助手：管理职位与简历、逐条核对职位要求、记录投递，从邮箱中发现面试邀请，并在你确认后写入 Apple 日历。

**所有数据只保存在你的 Mac 上，不上传任何服务器。**

## 下载

到 [Releases](https://github.com/lavenderhugo/zhicheng-releases/releases/latest) 下载最新版 `Zhicheng-<版本>.zip`。

系统要求：macOS 14 及以上（Apple 芯片与 Intel 均可）。

## 安装

1. 双击解压 zip，把 `Zhicheng.app` 拖到「应用程序」文件夹；
2. 本应用**未经 Apple 公证**，首次打开时系统会提示"无法验证开发者"。请打开「系统设置 → 隐私与安全性」，在页面底部点击"仍要打开"；
3. 或者在「终端」执行下面这条命令后再打开：

```bash
xattr -dr com.apple.quarantine /Applications/Zhicheng.app
```

可以用 Release 页面上的 SHA-256 校验下载文件是否完整：

```bash
shasum -a 256 ~/Downloads/Zhicheng-0.1.0.zip
```

## 能做什么

- **职位**：保存职位和要求，列表或看板查看投递进度；
- **简历**：导入 PDF 简历，核对提取的文字后保存；
- **匹配**：逐条查看职位要求在简历中是否有明确依据（不打分、不推断）；
- **投递记录**：在招聘网站完成投递后手动记录，职程不会替你投递；
- **面试**：连接 QQ 邮箱（只读）自动发现面试邀请，确认后写入你指定的 Apple 日历。

> **预览版说明**：职位、简历、匹配、投递记录和面试安排等本地功能已完成；QQ 邮箱同步和 Apple 日历写入**尚未在真实账户上完整验收**，使用时请留意识别结果，遇到问题欢迎反馈。

## 升级与卸载

- **升级**：退出应用，用新版本替换 `/Applications/Zhicheng.app`。升级后系统可能再次询问钥匙串或日历权限，选择"允许"即可，数据会保留；
- **卸载**：先在「设置 → 数据与隐私」中选择"清除全部本地数据"（会删除加密资料库、密钥和邮箱授权码），再删除 `Zhicheng.app`。

## 隐私

- 简历、职位、投递和面试信息加密保存在本机，密钥和邮箱授权码保存在 macOS 钥匙串；
- 邮箱只读取你选定的一个文件夹，不会标记已读、移动、删除或发送邮件；
- 写入日历前都会让你确认，不会修改或删除日历中的其他事项。
